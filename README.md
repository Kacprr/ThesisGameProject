# Ruins of North

**Ruins of North** is a 2D action-platformer developed as my Bachelor's thesis project in Computer Science.

The game focuses on challenging platforming, responsive movement, and combat. It was developed using **Godot Engine** and features mechanics such as jumping, dashing, attacking, stamina management, health management, and enemy encounters.

## 🎮 Play the Game

The completed game is available for free on itch.io:

**[Play Ruins of North on itch.io](https://loituma.itch.io/ruins-of-north)**

The itch.io page contains the downloadable builds and the latest release information.

## ✨ Features

* 2D platforming gameplay
* Responsive player movement
* Jumping and dashing mechanics
* Combat and attack system
* Enemy encounters
* Health and stamina systems
* Player animations and state-based movement
* HUD and gameplay interface
* Main menu and scene management
* Sound and music
* Windows release available through itch.io

## 🎓 Thesis Project

Ruins of North was developed as a Bachelor's thesis project in Computer Science.

The project was inspired by challenging platformers such as **Celeste**, **Super Meat Boy**, and **Jump King**, with a focus on learning and implementing core 2D game-development concepts.

The development process included designing player movement, implementing game states, creating combat mechanics, developing enemies, managing player health and stamina, and building the game's user interface.
